# RC Car

This is an Arduino Uno R4 WiFi based remote control car project, originally made as a part of a school project.

## Instructions

To be able to control the car connect your device to Arduino-Hotspots,  
when connect to the following IP-Address: [192.168.4.1](http://192.168.4.1)  
after that the website should look like this:

## Components

- The resistors being used are both 1kΩ
- The relays being used are G2RL-2 and RY211005
- The servo being used is SG90
